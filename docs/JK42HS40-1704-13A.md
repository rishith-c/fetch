Final FETCH motor. Manufacturer: JKONGMOTOR.

| Specification | Value |
|---|---:|
| Type | NEMA17, 2-phase bipolar, 4-wire |
| Step angle | 1.8° = 200 steps/revolution |
| Rated current | 1.7A per phase |
| Phase resistance | 1.5Ω |
| Phase inductance | 2.3mH |
| Holding torque | 0.42Nm |
| Body | 42×42×40mm |
| Shaft | 5mm D-cut |
| Mass | approximately 280g |
| Manufacturer coil colours | A+: black, A−: green, B+: red, B−: blue |
